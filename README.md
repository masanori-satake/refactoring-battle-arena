# 🚀 Refactoring Battle Arena

## 🌟 プロジェクトの目的
本プロジェクトは、三目並べのエージェント開発を通じて、リファクタリングの重要性と「読みやすく、変更に強いコード」を書く楽しさを体感するための挑戦状です。

単に動くだけのコードから、意図が明確に伝わり、将来の拡張を容易にする「メンテナンス性に優れたコード」への進化を目指してください。

## ⚔️ バトルのルール
1. **テストを死守せよ**: `test_logic.py` は変更禁止です。`pytest` を命綱にして、動作を保証しながらリファクタリングを進めてください。
2. **AI(ChatGPT等)は封印**: AIによる自動生成に頼らず、自分自身の指で設計原則をコードに落とし込んでください。自らの手で書き上げることで、真のスキルが身につきます。

## 🏆 二段階のミッション

### 【STEP 1】 ミニマム・サバイバル
3x3の三目並べで、次の手を選択するエージェントを実装してください。

- **基本仕様**:
  - 3x3の盤面（9要素のリスト）を受け取り、空いているマス（`None`）のインデックスを返す。
  - 自分がリーチ（あと1手で3つ並ぶ状態）の場合は、そのマスを優先的に選ぶ。
  - 相手がリーチの場合は、そのマスを阻止するように選ぶ。
  - 空きマスがない場合は `None` を返す。
- **課題**:
  - 基本仕様を満たしつつ、現状のコードをより読みやすく、メンテナンスしやすい形に自由に改善してください。

### 【STEP 2】 エキスパート・アップデート
エージェントに「性格（戦略）」の切り替え機能を追加します。

- **追加仕様**:
  - これまでの「通常（normal）」または「オリジナル（original）」戦略に加え、「角取り優先（空いていれば四隅を優先的に取る）」戦略を選択可能にしてください。
- **課題**:
  - **「既存のメインロジック（get_action等）を修正することなく」**、新しい戦略を追加できる柔軟な設計を目指してください。

## 🚩 作業フロー（ブランチとPR）
1. **基準ブランチ**: 運営が指定するブランチ（例: `round_1st`）を確認してください。
2. **マイブランチ（ベース）の作成**: 基準ブランチから `(基準名)_(社員ID)` という名前で自分用のベースブランチを作成します。
3. **ミッション開始**: ベースブランチから作業用（Work）ブランチを切り、ベースブランチに向けてマージするためのプルリクエスト（PR）を作成してください。
   - レビューアには主催者と仲間を招待し、積極的にフィードバックをもらいましょう！
