## ⚔️ バトルのルール
1. **テストを死守せよ**: `test_logic.py` は変更禁止。`pytest` を命綱にしてください。
2. **AI(ChatGPT等)は封印**: 自分の指で原則を書き込んでください。メッキは剥げます。

## 🚩 作業フロー（ブランチとPR）
1. **基準ブランチ**: 運営が指定するブランチ（例: `round_1st`）
2. **自分のフィールド(ベース)**: 基準ブランチから `(基準名)_(社員ID)` ブランチを作成。
3. **ミッション開始**: 自分のベースから Workブランチを切り、自分のベースに向けてマージするPRを作成してください。レビューアには主催者と仲間を招待しましょう！

## 🏆 二段階のミッション

### 【STEP 1】 YAGNI：不要な予測を刈り取る
**目標：今の仕様に不要なコードをすべて消し去る**
初期コードには「将来の拡張」を夢見た無意味な引数や処理が蔓延しています。
- **課題**: 「いつか使うかも」をすべて捨て、3x3の三目並べを最もシンプルに実装してください。
- **合格基準**: コードが激減し、一目で全体が把握できるほどシンプルになっていること。

### 【STEP 2】 OCP：既存コードを汚さずに進化させる
**目標：AIに「性格（戦略）」を追加する**
STEP 1をクリアしたコードに、新しい仕様を追加します。
- **追加仕様**: AIに「勝利優先」に加え、「角取り優先（四隅を狙う）」の戦略を持たせ、実行時に切り替え可能にしてください。
- **真の課題**: **「既存のメインロジック（get_action等）を1文字も修正せずに」**、この新戦略を追加できますか？
- **合格基準**: 戦略を「プラグイン」のように差し込める設計（Strategyパターン等）になっていること。
