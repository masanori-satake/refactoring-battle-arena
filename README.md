# 🚀 Refactoring Battle Arena

## 🌟 プロジェクトの目的
本プロジェクトは、三目並べのエージェント開発を通じて、「読みやすく、変更に強いコード」を書くことを実践し、リファクタリングの楽しさとテストの重要性を体感するものです。

単に動くだけのコードから、レビューアや他者に意図が明確に伝わり、将来の拡張を容易にする「メンテナンス性に優れたコード」への進化を目指してください。

## ⚔️ グランドルール
1. **テストを死守せよ**:<br>`tests/test_logic.py` および `tests/logic.test.js` は変更禁止です。テストをセーフティネットにして、動作を保証(グリーン)しながらリファクタリングを進めてください。
2. **AI(ChatGPT,Gemini等)利用はちょっとお休み**:<br>AIによるコードの自動生成に頼らず、自身の手で設計原則をコードに落とし込んでください。自らの手で書き上げることで、実践できるスキルが身につきます。<br>※検索はOK!!
3. **他者の良いコードはさっさと盗め**:<br>先行者の**よいコード**を見つけたら、尊敬/敬意をもって盗みましょう。そして、さらに良いコードをお見舞いしてあげましょう。<br>`(先行者=コミットログが1秒でも早かった人)`

## 🏆 2段階のバトル

### 【Basic Battle】 **"POLISH"**
3x3の三目並べで、次の手を選択するエージェントを実装してください。

- **基本仕様(戦略=`normal`)**:
  - 3x3の盤面（9要素のリスト）を受け取り、空いているマス（`None`）の中から置きたいマスのインデックス(0～8)を返す。
  - 自分がリーチ（あと1手で3つ並ぶ状態）の場合は、そのマスを優先的に選ぶ。
  - 相手がリーチの場合は、そのマスを阻止するように選ぶ。
  - 空きマスがない場合は `None` を返す。
- **課題**:
  - 基本仕様を満たしつつ、現状のコードを**より読みやすく、メンテナンスしやすい**形に自由に改善してください。
- **注意**:
  - `AGENT_NAME` には予約されている`"original_py"`や`"original_js"`という名前の使用は**禁止**されています。

### 【Advanced Battle】 **"BE STRONG"**
エージェントに「戦略」の切り替え機能と、盤面サイズ拡張への対応を追加します。

- **追加仕様**:
  - これまでの「通常（戦略=`normal`）」に加え「オリジナル（original）」の戦略を追加してください
    - 例えば「角取り優先（空いていれば四隅を優先的に取る）」といったオリジナルの戦略(戦略=`original`)を選択可能にしてください。
  - **盤面サイズの拡張対応**: 3x3 だけでなく、N x N（N=3～10,例: 4x4, 5x5...）の盤面でも動作するように設計を変更してください。
- **課題**:
  - **「既存のメインロジック（get_action等）を修正することなく」**、新しい戦略を追加できる柔軟な設計を目指してください。

## 🚩 作業フロー（ブランチとPR）
1. **基準ブランチ**: 運営が指定するブランチ（例: `round-1st`）を確認してください。
2. **マイブランチ（ベース）の作成**: 基準ブランチから `(基準名)_(社員ID)` という名前で自分用のベースブランチ(例: `round-1st_(社員ID)`)を作成します。
3. **ミッション開始**: ベースブランチ(例: `round-1st_(社員ID)`)から作業用（Work）ブランチを切り、作業をします。<br>作業がひと段落したらベースブランチ(例: `round-1st_(社員ID)`)に向けてマージするためのプルリクエスト（PR）を作成してください。
   - レビューアには主催者と仲間を招待し、積極的にフィードバックをもらいましょう！
   - 自身でテーマを決めて「作業ブランチ作成→作業→PR作成」を複数回実施しましょう。<br>レビューアがレビューしやすい単位でPRを出しましょう。
   - 作業ブランチは、使いまわしても、PR終了後に消してもOKです。作業とレビューのしやすさを優先して決めてください。

## 🏆 天下一武道会（Advanced Battle用トーナメント）
リファクタリングし、オリジナルの戦略を持ったエージェントの実力を試す場として、総当たり戦を開催できます。

- **勝敗判定**: 複数の対戦を行い、統計的な有意差がある場合に勝敗を決定します。
  - 乱数の運/不運では勝てないように判定します。
- **ポイントシステム**: 勝利で3点、引き分けで1点を獲得し、合計得点で順位を競います。
- **ランキング**: 3チーム以上の参加で順位が表示されます。同点の場合は、そのスコアに応じた順位（最高得点は常に1位）が付与されます。
